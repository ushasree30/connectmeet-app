# 🤝 ConnectMeet

ConnectMeet is a full-stack web application designed to provide a simple platform for users to connect and interact. It combines a modern React frontend with a Spring Boot backend.

## ✨ Features

- Clean and responsive user interface
- React-based frontend
- Spring Boot backend
- REST API support
- Separate frontend and backend structure
- Easy local development setup
